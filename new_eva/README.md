# Sistema HUV - Laravel

## 🏥 Sistema de Gestión Hospitalaria

Sistema completo de gestión de equipos biomédicos e industriales para hospitales.

### ✨ Características Principales
- 🔧 Gestión de equipos biomédicos e industriales
- 📋 Órdenes de trabajo y mantenimientos
- 👥 Gestión de usuarios y permisos
- 📊 Reportes y estadísticas avanzadas
- 📱 API REST y aplicación móvil
- 🔒 Sistema de auditoría y seguridad

### 🚀 Tecnologías
- **Framework**: Laravel 10+
- **Base de datos**: MySQL
- **Frontend**: Blade Templates + AdminLTE
- **API**: RESTful

### 📊 Estadísticas del Sistema
- **256 Controladores** con funcionalidades completas
- **256 Modelos** para gestión de datos
- **1000+ Rutas** configuradas
- **65 Módulos** organizados

### 🛠️ Instalación
```bash
# Clonar repositorio
git clone [url-repositorio]

# Instalar dependencias
composer install
npm install

# Configurar entorno
cp .env.example .env
php artisan key:generate

# Migrar base de datos
php artisan migrate

# Iniciar servidor
php artisan serve
```
